# Obtainium Android Recomps

A curated pack of native Android ports, decompilations and recompilations of classic games for [Obtainium](https://github.com/ImranR98/Obtainium).
<br>Import one file and get automatic updates for every port, straight from each project's GitHub releases.

[![GitHub Release](https://img.shields.io/github/v/release/heyalmoo/Obtainium-Android-Recomps?label=latest%20release)](https://github.com/heyalmoo/Obtainium-Android-Recomps/releases/latest)

</div>

---

These are not emulators. Each app is a community project that rebuilds a classic game's engine to run natively on Android, through decompilation, static recompilation or a source port.

I maintain this pack mainly for myself and play on a Retroid Pocket Nova. Nothing in it is specific to that device, though: the apps are standard arm64 Android builds.

Other recomp packs exist, such as [Obtainium-Recomp-Decomp](https://codeberg.org/BBoi34/Obtainium-Recomp-Decomp) on Codeberg. This one is stricter: I test every game here myself and only add projects that are already comfortably playable, not early builds that barely run. If a project stalls or is abandoned, or a new fork takes over, I update the list to match.

## Getting Started

### 1. Install Obtainium

Download the [latest release of Obtainium](https://github.com/ImranR98/Obtainium/releases/latest) and install it on your device. If you're unsure which APK to grab, use `app-release.apk`.

### 2. Import the Pack

1. On your device, open the [latest release](https://github.com/heyalmoo/Obtainium-Android-Recomps/releases/latest).
2. Download `obtainium-android-recomps-vX.X.X.json`.
3. In Obtainium, go to **Import/Export** > **Obtainium Import** and select the file.

All ports appear in the **Recomp** category, and Obtainium will keep them up to date.

Importing only adds apps. It does not remove anything or change your Obtainium settings, so it is safe to use next to other packs such as [Obtainium Emulation Pack](https://github.com/RJNY/Obtainium-Emulation-Pack).

## What's in the Pack

> [!IMPORTANT]
> **This is a bring-your-own-game pack. No games are included.**
> Obtainium only downloads the Android apps (APKs) that run each decompilation or recompilation, straight from the projects' official GitHub releases. No game data, ROMs or copyrighted assets are included in this pack or distributed by this repository. Each app needs game files from a copy you legally own; see the project's own README for setup.

Don't want the whole pack? Open this page on your device and tap **Add to Obtainium!** for just the apps you want.

## Updating the Pack

The pack includes itself as a **track-only** app. When a new version of this list is released, Obtainium will notify you, just like an app update.

Obtainium cannot import a pack by itself, so the update is one manual step: open the release, download the new JSON and import it again. New ports are added, and the apps you already have stay as they are.

## FAQ

**Will this replace my other Obtainium apps or packs?**
No. Obtainium has one shared app list, and an import only adds apps. Nothing is removed or overwritten, and this pack has no `settings` block.

**Where do I get the games?**
From copies you own. This repository does not provide, link to or help find game files, and issues asking for them will be closed. Each project's README explains which version of the game it supports.

**An app is missing or a link broke.**
[Open an issue](https://github.com/heyalmoo/Obtainium-Android-Recomps/issues) with a link to the project's releases page.
